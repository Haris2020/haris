## Dubai Golden Visa – Contact Email

The official email to contact for Dubai Golden Visa applications is:

**amer@gdrfad.gov.ae**

This is the email for the **General Directorate of Identity and Foreigners Affairs – Dubai (GDRFA Dubai)**, which handles Golden Visa services.

### How to Apply

1. Visit the official GDRFA Dubai portal: [gdrfad.gov.ae](https://www.gdrfad.gov.ae/en)
2. Or apply via ICP Smart Services: [icp.gov.ae](https://icp.gov.ae)
3. Schedule a Golden Visa appointment at: [gdrfad.gov.ae/en/golden-visa-appointment](https://www.gdrfad.gov.ae/en/golden-visa-appointment)
4. For property investors, apply via Dubai Land Department: [dubailand.gov.ae](https://dubailand.gov.ae/en/eservices/request-for-golden-visa-investor/)
